Botezuma Discord Alerts

TikTok alerts for Discord

Connect TikTok to demonstrate how Botezuma will read recent public videos from an authorized TikTok account and announce them inside a Discord server.

Privacy Policy Terms

This page is a minimal review/demo page for TikTok Developer. It does not store tokens in the browser. The production Discord bot will use private server environment variables.

Integration flow

  1. Owner clicks Connect TikTok.
  2. TikTok Login Kit asks for permission.
  3. The app requests user.info.basic and video.list.
  4. Botezuma reads recent public TikTok videos from the authorized account.
  5. When a new video is detected, Botezuma posts a Discord alert.
